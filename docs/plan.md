# 재정공개 수집·공개 계획

선린인터넷고등학교와 용산경찰서가 공시한 재정 자료를 전건 수집해, 조회 가능한
정적 페이지와 읽기 전용 REST API로 제공하는 작업의 계획과 현재 상태.

## 목표

1. 공시 자료를 원본 그대로 CSV로 보존한다.
2. 기간을 좁혀 사용처·업체 순위를 볼 수 있는 페이지를 제공한다.
3. 같은 데이터를 JSON API로도 제공해 다른 도구가 쓸 수 있게 한다.
4. 기계로 읽은 값이므로, 원본 합계와 어긋나는 구간을 숨기지 않고 명시한다.

## 데이터 출처

| 대상 | 출처 | 접근 방식 |
| --- | --- | --- |
| 선린인터넷고 학교회계 | 서울특별시교육청 열린 서울교육 재정공개 (`open.sen.go.kr`, schoolCode 7010536, NEIS B100000658) | JS 기반 목록·상세를 POST로 직접 호출 |
| 용산경찰서장 업무추진비 | 서울경찰청 용산경찰서 서장업무추진비공개 게시판 (`smpa.go.kr`, ps_opendata_id 113) | 게시글 목록 → 첨부 PDF 다운로드 → 표 파싱 |

두 기관 모두 공식 Open API를 제공하지 않는다. 열린 서울교육은 JS로 렌더링되는
HTML만, 용산경찰서는 PDF 첨부만 준다. 따라서 이 저장소의 데이터는 사본이며
실시간 갱신은 불가능하고, 갱신은 수집 스크립트를 다시 돌려야 한다.

## 완료된 작업

### 수집

- 선린 세부사업 집행실적 12,908행 (2012년 4분기 ~ 2026년 9월)
- 선린 수의계약 3,037건 (상세가 남아 있는 2021년 12월 ~ 2026년 9월)
- 선린 업무추진비 2,533건 (2012년 12월 ~ 2026년 8월)
- 선린 결산·세입·세출·예산 회차·학교발전기금 요약표
- 용산경찰서장 업무추진비 1,203건 (2016년 1월 ~ 2026년 9월, PDF 131개)

### 산출물

- `site/index.html` — 선린 재정공개 페이지. 결산 타일, 세출·세입 구성 비교,
  예산 회차 추이, 업무추진비 장소 순위(기간 슬라이더·상호 병합 토글),
  수의계약 업체 순위, 세부사업 집행실적 표.
- `site/police.html` — 용산경찰서장 업무추진비 페이지. 기간 슬라이더,
  연도 바로가기, 건수/금액 정렬 전환, 월별 집행액 막대, 전건 표, 구멍 명시.
- `site/data/*.csv`, `data/*.csv` — 수집 결과 CSV.
- `api.py` — FastAPI 기반 읽기 전용 API. 엔드포인트 17개, `/docs`에 Swagger UI,
  `/openapi.json`에 스키마. 시작 시 CSV를 메모리에 적재(약 3MB).

### 검증

- 수집 누락: 기간별 행 번호의 빈칸을 전수 점검해 메움(0 holes).
- 용산경찰서 PDF: 각 달의 파싱 합계를 PDF에 적힌 합계와 대조. 128개월 중
  123개월 일치.
- API: 소켓을 열지 않고 ASGI를 직접 호출해 전 엔드포인트 응답과 합계를 확인.

## 알려진 데이터 구멍

숨기지 않고 페이지와 `/datasets` 응답에 그대로 노출한다.

- 선린 수의계약: 목록에는 2012년 12월부터 166개월이 있으나 상세는 2021년 12월
  이후만 서버에 남아 있다. 2019년 6월·2021년 4월·2022년 1월 등을 직접
  재확인했고 모두 "승인된 건이 없습니다" 응답.
- 선린 업무추진비 2026년 9월, 집행실적 2014년 1분기: 같은 이유로 공백.
- 용산경찰서 2015년 12월 이전 게시글 38건: 본문·첨부에 내역 자체가 없다.
- 용산경찰서 2016년 2월: 첨부가 스캔 이미지라 텍스트 추출 불가.
- 용산경찰서 2016년 12월, 2017년 3월·4월, 2023년 4월, 2024년 10월: 월 합계가
  PDF에 적힌 합계와 어긋난다. 표가 여러 줄로 쪼개진 행을 놓친 것으로 보인다.

## 개인정보 처리

저장소가 공개되어 있으므로, 공시 원본에 실명으로 남아 있는 개인만 가린다.
업체명·기관명·금액·날짜·집행목적은 손대지 않는다. 마스킹 방식은 공시 원본이 이미
쓰고 있는 관례(`박O은`, `교사 하ㅇㅇ`)를 따른다.

- 업무추진비 `집행장소` 가 개인 수령인인 경우(80명·162행) → `개인`
- `승인자` 실명 → 가운데를 `O` 로
- `참석자` 의 `직위 실명` → 가운데를 `O` 로
- 상호에 사업주 실명이 들어간 경우 → 상호는 남기고 이름만 가림

규칙은 `scripts/anonymize.py` 에 있다. 개인 수령인 판별은 집행목적이 개인 지급
(경조·수당·강사료 등)인 행의 집행장소를 모아 표 전체에 적용하는 방식이다.
휴리스틱이 업체를 개인으로 잘못 잡는 경우는 `BUSINESS_EXCEPTIONS` 에 직접 적어 둔다.

## 남은 작업

1. **어긋난 5개 달 파서 보정** — 쪼개진 행 병합 로직을 넓혀 월 합계를 PDF 명시
   합계와 맞춘다. 2016년 2월은 OCR 없이는 불가.
2. **학교 카드 사용내역 미수집** — 열린 서울교육에는 `creditCard` 표
   (`사용일자·사업업체명·사용금액·사용내역`)도 있는데 아직 받지 않았다.
   엔드포인트는 `/fus/MI000000000000000517/creditCard/list0010d.do` 로 다른 표와 같은 꼴이다.

## 갱신 절차

증분 수집 스크립트를 `scripts/` 에 넣었다. 과거 전체를 다시 긁지 않고, CSV 에 없는
기준월·게시글만 받는다. cron 등록은 README 를 참고한다.

| 스크립트 | 역할 |
| --- | --- |
| `scripts/update.py` | 진입점. 없는 달만 골라 받고, 마스킹한 뒤 CSV 재작성 |
| `scripts/update_school.py` | 열린 서울교육 목록 첫 장 → 새 기준월만 상세 조회 |
| `scripts/update_police.py` | 경찰서 게시판 첫 장 → 새 글의 PDF 만 받아 표 파싱 |
| `scripts/anonymize.py` | 개인 이름 마스킹 |
| `scripts/sources.py` | HTTP 호출·재시도·HTML 표 파싱 |
| `scripts/cron_update.sh` | cron 진입점. 수집 → 커밋 → push → 컨테이너 재시작 |

### 엔드포인트

열린 서울교육은 표마다 목록 `list0010v.do` 와 상세 `list0010d.do` 가 있다.
상세는 `stdr_month` 로 한 달을 걸러 `detPageIndex` 로 10행씩 넘긴다.

| 표 | 경로 |
| --- | --- |
| 업무추진비 (`expense`) | `/fus/MI000000000000000514/finance/` |
| 수의계약 (`contracts`) | `/fus/1/contractOpen/` |
| 집행실적 (`execution`) | `/fus/MI000000000000000519/estimate/` |

용산경찰서는 목록 `psDeclareBoardList.do?ps_opendata_id=113` → 본문
`psDeclareBoardView.do` (`boardNo`) → 첨부 `attachfileDownload.do?attachNo=` 순서다.

서버는 요청마다 10~20초가 걸리고 간헐적으로 빈 응답을 돌려주므로, 모든
스크립트는 재시도를 전제로 작성되어 있다. 동시 요청은 10개를 넘기지 않는다.
